# Fashora - AI Powered Full-Stack E-Commerce Platform

Fashora is a production-ready full-stack e-commerce platform focused on performance, conversion, and intelligent shopping experiences.

## Highlights

- Built with MERN architecture for scalable product, order, and user management.
- Integrated Gemini AI features for smarter search, recommendations, and assistance.
- Stripe-powered secure checkout with robust payment flow handling.
- Redis + BullMQ for queue-driven background jobs and smoother runtime performance.
- Socket.IO for real-time updates across key user interactions.

## Core Stack

MERN, Gemini AI, Stripe, Redux Toolkit, BullMQ, Redis, Socket.IO, Cloudinary.
