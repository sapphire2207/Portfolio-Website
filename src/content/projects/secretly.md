# Secretly - AI Powered Anonymous Messaging Platform

Secretly is an anonymous messaging platform designed for secure communication and modern product workflows.

## Highlights

- Built on Next.js 16 and React 19 with type-safe architecture.
- Anonymous messaging flow with authentication and protected routes.
- Gemini AI-assisted suggestions to improve user message quality.
- Validation-first forms using Zod for reliable user input handling.
- Email workflows via Resend for account and product notifications.

## Core Stack

Next.js 16, React 19, TypeScript, NextAuth, MongoDB, Zod, Resend, Gemini AI.
